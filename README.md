# Hangul de Berenice 🌸

App para aprender coreano (y practicar inglés) desde cero: escribir hangul con Apple Pencil o el dedo, lecciones, vocabulario, pronunciación y traductor.

Se puede instalar en el iPad o el celular: en Safari, botón Compartir → "Agregar a pantalla de inicio".

Archivos: `index.html` (la app), `manifest.webmanifest` + `sw.js` (instalable y funciona sin internet), `icons/` (logo).

## Trazo 📐

En la carpeta `trazo/` está **Trazo**, el visor de planos de Berenice (marcar, cuantificar y hacer observaciones con Apple Pencil). Se abre en `https://berenicegmz23-del.github.io/hangul-berenice/trazo/` y se instala igual: Safari → Compartir → "Agregar a pantalla de inicio". Tiene su propio ícono, `manifest.webmanifest` y `sw.js`. Los planos se guardan solo en el aparato.
